# sprout — AI 리딩 파트너 (SQLD 제63회 대비 프로토타입)

학습자료를 읽는 과정에서 **이해시키고 → 스스로 이해했는지 확인하고 → 그 결과를 다음 학습까지 기억하는** AI 학습 에이전트.
Notion 데스크 리서치·PRD와 Figma 와이어프레임을 기반으로, 인프런 스타일(그린 #00C471, Pretendard, 블랙 플레이어 헤더 + 우측 아이콘 레일)로 구현했습니다.

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
```

Claude 연결(선택): `ANTHROPIC_API_KEY`를 설정하고 실행하면 AI 패널 답변이 `claude-opus-5-5`로 생성됩니다.
키가 없으면 학습 자료 기반 데모 응답으로 동작합니다(워크스페이스 상단에 `데모 모드` / `Claude 연결됨` 표시).

```bash
ANTHROPIC_API_KEY=sk-ant-... npm run dev
```

## 화면 (PRD 플로우)

| 경로 | 화면 | 주요 기능 |
| --- | --- | --- |
| `/login` | 로그인 | 온보딩 + Google 로그인(목업) |
| `/setup` | 시험·목표 설정 | 공식 시험정보(출처 표시), 하루 공부시간, 6문항 위치 진단(확신도 포함) → 합격 예상 점수 |
| `/my` | 내 학습 메인 | D-day·예상 점수, 오늘의 학습(시간에 맞춰 재구성), 개념별 이해도, 간격 반복 복습 예정, 최근 오답·노트 |
| `/my/library` | 강의실(자료실) | 자료 리스트·진도 |
| `/my/records` | 학습 기록 | 최초/재시도 정답률, 개념별 이해도, 오답 원인 분포, 반복 오답, 확인 기록, 노트 |
| `/learn/:id` | 학습 워크스페이스 | 학습 자료 + AI 패널(에이전트 / 요약 / 복습 / 노트) |

## 역할 분리 (리서치 원칙)

- **AI**: 설명, 질의응답, 예시·비교, 다음 행동 제안 (`server/agent.ts`, 오프라인 대체: `src/lib/agent.ts`)
- **시스템**: 정답 판정, 오답 원인 태깅(선지별 오개념 매핑 + 확신도), 이해도 계산, 복습 시점(1·3·7·14일) — `src/store.tsx`, `src/data/questions.ts`
- **사용자**: 시험 목표, 공부 시간, 확신도 입력

학습 기록은 브라우저 localStorage에 저장됩니다.
